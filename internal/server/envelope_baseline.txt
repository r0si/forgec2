# Raw `c.JSON(http.StatusOK, ...)` call sites per file: the remaining half of
# the Option-A envelope migration.
#
# Every JSON 200 body from this server is {"success": true, "data": ...} (see
# respond in helpers.go); a handler that writes c.JSON(http.StatusOK, ...)
# directly still emits a bare payload, which is the inconsistency this
# migration removes. This file pins today's count per file so the migration can
# land in batches: TestSuccessEnvelope fails when a file grows past its count
# (new debt) and also when it drops below it (lower the number in the same
# commit, so the list cannot go stale).
#
# To migrate a site: replace
#     c.JSON(http.StatusOK, gin.H{...})
# with
#     respond(c, gin.H{...})
# (dropping any hand-built "success" key), then decrement the file's number
# here. Sites that must stay raw (a non-JSON body, a streaming handler) belong
# in the allowlist in the test instead of this file.
