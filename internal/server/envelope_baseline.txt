# The migration is complete: every JSON 200 goes through respond() except the
# entries below, and each has a reason rather than being debt.
#
#   helpers.go     respond() itself, the one place that writes the envelope.
#   api.go         REST v1 list shapes: {"success": true, "data": [...],
#                  "total": n}, published in api/openapi.yaml for scripting
#                  clients. Moving total inside data would break them.
#   extc2.go       the external-C2 protocol reply struct (extC2SendResponse),
#                  whose Success field is part of that wire format.
#   render_api.go  renderPageOrJSON emits HTML/JSON page documents, not API
#                  payloads; wrapping them would change the page JSON contract.
#   server_http.go /health, whose status/version/uptime keys container and
#                  deploy probes read at the top level.
#   audit.go       the format=json audit export is ONE document
#                  (count/truncated/filtered/rows) for tools that do not
#                  stream; the NDJSON variant is not JSON at all.
#   handlers_agent_tasks.go  the format=json task export, same reasoning: a
#                  single document with count/truncated/tasks, whose rows a
 #                  caller asked for by name.

api.go 4
